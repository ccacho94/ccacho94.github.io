Artifact Enhancements

Each enhancement builds on the same Android weight-tracking application and demonstrates a different area of computer science.

01

Software Design & Engineering

The first enhancement refactors the application toward the MVVM architecture. UI responsibilities are separated from application logic and data access through ViewModels, LiveData, model classes, and repositories. This makes the application easier to maintain, test, debug, and expand.

Skills: Java, Android Studio, MVVM, ViewModel, LiveData, object-oriented design, separation of concerns

View Enhancement One →
02

Algorithms & Data Structures

The second enhancement adds weight-trend analysis. Weight entries are organized by date and evaluated to determine whether the user's weight is increasing, decreasing, or staying the same. The enhancement demonstrates MergeSort, ArrayList operations, binary search concepts, and Big-O analysis.

Skills: MergeSort, ArrayList, binary search, date comparison, algorithm analysis, Big-O notation

View Enhancement Two →
03

Databases

The third enhancement improves the SQLite database used to store users, goals, and weight entries. The database design focuses on stronger relationships, safer queries, user-specific record access, password protection, validation, indexing, and more reliable data handling.

Skills: SQLite, relational database design, CRUD operations, parameterized queries, foreign keys, indexing, validation, security
