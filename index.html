Professional Self-Assessment

During my Computer Science studies at Southern New Hampshire University, I gained skills that prepare me for a career in the field and ongoing growth as a software professional. Reflecting on my experience, I realize I learned much more than coding, including collaborating with others, communicating technical concepts, understanding user needs, managing projects and deadlines, solving problems through logic and algorithms, developing applications and databases, and considering security throughout the development process. These experiences have highlighted my strengths and helped guide my professional goals.

A key area of my professional growth was learning to work effectively in a team setting. I participated in activities where I assumed different roles within a software development team. This experience showed me how individuals with different responsibilities collaborate toward common objectives and how each role contributes to the success of a project. I also gained familiarity with Agile practices, Kanban boards, and time management strategies. Using a Kanban board allowed me to organize tasks based on whether they needed to be completed, were in progress, or were finished. I learned to break larger projects into smaller, manageable tasks, prioritize requirements, and improve my time management. These experiences emphasized the importance of communication, teamwork, organization, and understanding the responsibilities of others in a development environment.

UI/UX design strengthened my ability to communicate with stakeholders and understand their needs. I created a wireframe for a health application while considering what information users needed, how they would navigate between screens, and how important features could be made easy to find and understand. The wireframe helped me translate stakeholder requirements into a visual design and allowed changes to be made before development began. This experience taught me that developers need to consider both technical requirements and the needs of the people using the application. It also helped me view software from the user's perspective rather than focusing only on whether the code worked correctly.

Studying data structures and algorithms, along with mathematics courses such as Discrete Mathematics, strengthened my problem-solving and analytical skills. Discrete Mathematics deepened my understanding of logic, sets, functions, relations, and mathematical reasoning, which are fundamental to computer science. It taught me to break complex problems into smaller steps and apply logical reasoning to find solutions. I applied this way of thinking when working with data structures and algorithms. I learned how different data structures organize information and how algorithms can be used to search, sort, and process data. I also learned about algorithm efficiency and Big O notation, which helped me understand why one solution may be more efficient than another. Together, these areas taught me to think more logically about programming problems and consider both the correctness and efficiency of the solutions I develop.

Software engineering and database development gave me experience building applications and understanding how different technologies work together. One project outside my ePortfolio artifacts was the Travlr Getaways full-stack web application. Through this project, I used Angular to develop a single-page application and Node.js with Express for the backend. I also used REST APIs and MongoDB to store and retrieve application data. I used Postman to test GET, POST, and PUT requests and verify that information was transferred correctly between the application and the database. Working through this project helped me better understand how the front end, backend, API, and database communicate with one another to create a complete application.

Security was another important area that changed how I approach software development. I learned that security should be considered throughout the development process rather than only after an application is completed. While developing web applications, I gained experience with user authentication, password protection, JSON Web Tokens, input validation, and controlling access to protected functionality. I learned why passwords should not be stored as plain text and how password hashing can help protect user credentials. I also learned the importance of validating user input and making sure users can only access information and functions they are authorized to use. These experiences helped me develop a security-focused mindset that I can continue applying to future software projects.

Another strength I developed throughout the program is my ability to troubleshoot and manage my work independently. There were many times when an application did not work as expected, even when the code initially appeared correct. I learned to use error messages, debugging tools, browser developer tools, Postman, and testing to pinpoint where problems were occurring. Instead of trying to solve an entire problem at once, I became more comfortable breaking problems into smaller pieces and testing each part individually. Combining these troubleshooting skills with Agile practices, Kanban, and time management helped me become more organized and better prepared to manage larger development projects and meet deadlines.

Overall, completing the Computer Science program has prepared me for a career in the field and underscored the importance of both technical and professional skills. I have become more confident in my ability to solve problems, develop effective solutions, collaborate with others, and continue learning as technology evolves.

CS-499 Capstone

Artifact Enhancements

Each enhancement builds on the same Android weight-tracking application and demonstrates a different area of computer science.

01

Software Design & Engineering

The first enhancement refactors the application toward the MVVM architecture. UI responsibilities are separated from application logic and data access through ViewModels, LiveData, model classes, and repositories. This makes the application easier to maintain, test, debug, and expand.

Skills: Java, Android Studio, MVVM, ViewModel, LiveData, object-oriented design, separation of concerns

View Enhancement One →
02

Algorithms & Data Structures

The second enhancement adds weight-trend analysis. Weight entries are organized by date and evaluated to determine whether the user's weight is increasing, decreasing, or staying the same. The enhancement demonstrates MergeSort, ArrayList operations, binary search concepts, and Big-O analysis.

Skills: MergeSort, ArrayList, binary search, date comparison, algorithm analysis, Big-O notation

View Enhancement Two →
03

Databases

The third enhancement improves the SQLite database used to store users, goals, and weight entries. The database design focuses on stronger relationships, safer queries, user-specific record access, password protection, validation, indexing, and more reliable data handling.

Skills: SQLite, relational database design, CRUD operations, parameterized queries, foreign keys, indexing, validation, security
