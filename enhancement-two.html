Enhancement Two: Algorithms & Data Structures

Enhancement Overview

For this enhancement, I added a weight-trend feature that analyzes a user's weight history. The enhancement focuses on organizing weight entries by date, comparing the newest records, and applying algorithms and data structures in a practical feature.

Original Artifact

The original application stored weight entries in an ArrayList and could determine whether a user reached a goal, but it did not analyze changes over time. Entries could also be ordered by entry ID instead of the actual date, which could produce incorrect results when older dates were entered later.

Enhancements Completed

  • Used an ArrayList to store WeightEntry objects for analysis.
  • Added MergeSort logic to organize entries chronologically.
  • Compared the two most recent entries to identify whether weight is increasing, decreasing, or staying the same.
  • Separated trend logic into a dedicated WeightTrendAnalyzer class.
  • Applied binary-search concepts for locating entries by date after sorting.
  • Evaluated runtime using Big-O notation, including O(n log n) MergeSort and O(log n) binary search.
  • Considered HashMap use for grouping entries by user while evaluating whether it provides a practical benefit.
  • Added date validation so future or inconsistent dates do not produce incorrect trend results.

Course Outcome Connection

This enhancement primarily supports the ability to design and evaluate computing solutions using algorithmic principles while considering trade-offs. MergeSort provides reliable O(n log n) performance but requires O(n) additional memory, while binary search improves searching to O(log n) after the data has been sorted.
