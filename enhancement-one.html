Enhancement One: Software Design & Engineering

Enhancement Overview

I selected my weight-loss tracking application, which I originally created for my CS-360 Mobile Architecture and Programming course at the beginning of 2026. The Android application allows users to create an account, log their weight, set a target weight, view previous entries, and receive a notification when they reach their goal.

I selected this artifact because I would eventually like to publish it on the Google Play Store for others to use. Feedback from real users would help me continue improving the application and provide additional real-world software development experience.

Original Artifact

The original application demonstrated my proficiency with Java, Android Studio, XML layouts, SQLite databases, user input validation, account management, and goal-tracking logic.

Before the enhancement, the activity files handled several responsibilities at the same time, including the user interface, input validation, database calls, and application logic. This made the application more difficult to maintain, test, and expand.

To understand where improvements could be made, I examined the activity files method by method to determine which sections controlled the interface, handled validation, or communicated with the database. This allowed me to understand the dependencies between methods before reorganizing the application.

Enhancements Completed

  • Reorganized the application into separate model, view, ViewModel, repository, data, and utility packages.
  • Added ViewModel classes, including WeightLogViewModel and LoginViewModel, to handle validation and communication between the user interface and data.
  • Added repository classes to separate the ViewModels from DatabaseHelper.
  • Reduced the responsibilities of the activity files so they mainly collect user input and update the screen.
  • Moved application decisions and validation logic into the ViewModel layer.
  • Moved database requests into repository classes.
  • Improved separation of concerns throughout the application.
  • Created a structure that is easier to maintain, test, debug, and expand with future features.

Skills Demonstrated

This enhancement demonstrates my ability to analyze existing code and understand how different parts of an application work together. I reorganized the code into smaller and more focused classes while preserving the existing functionality of the application.

Course Outcome Connection

This enhancement supports Course Outcome Four because I used well-founded software development techniques and tools to improve the design of my application. Refactoring the application into an MVVM structure allowed me to separate the user interface, application logic, and database operations into more focused layers.

This demonstrates my ability to apply an industry-standard design pattern and create a computing solution that is easier to maintain, test, and expand. The improved organization also provides more value because future features can be added without placing additional responsibilities directly inside the activity files.

Challenges and Lessons Learned

While enhancing the application, I learned that reorganizing existing code requires more than moving files into different folders. Package declarations, imports, activity references, database calls, and method names must all be updated so the classes continue working together.

One challenge was deciding which code belonged in each layer because some of the original activity files handled several responsibilities. I carefully examined the code, determined how the methods were connected, and decided which parts should remain in the View and which should move into the ViewModel or repository.

The weight entries are still displayed using a GridLayout. A future improvement will be replacing the GridLayout with a RecyclerView. For this enhancement, I focused first on separating the code and improving the overall application structure using MVVM because the structure needed improvement before additional interface changes were added.

This process helped me better understand separation of concerns and demonstrated how stronger organization can make testing, debugging, maintenance, and future development easier.

Future Improvements

I plan to continue improving the application by replacing the GridLayout with a RecyclerView and strengthening security through improved password storage, additional input validation, and stronger error handling.
