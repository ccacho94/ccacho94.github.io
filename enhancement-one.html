Enhancement One: Software Design & Engineering

Enhancement Overview

For this enhancement, I refactored my Android weight-tracking application to improve its structure and maintainability. The original application placed too much application logic, database access, and UI behavior directly inside Activities. I reorganized the project using MVVM concepts so each part of the application has a clearer responsibility.

Original Artifact

The original application successfully supported account registration, login, goal management, weight tracking, record deletion, and optional SMS notifications. However, the Activities were tightly connected to database and business logic, which made the application harder to test and maintain.

Enhancements Completed

  • Introduced ViewModel classes to move application logic away from Activities.
  • Used LiveData so the user interface can observe weight-entry and trend changes.
  • Separated model, view, and application-logic responsibilities.
  • Improved the organization of weight-entry deletion and goal-related logic.
  • Reduced direct database and business-logic dependencies inside the UI layer.
  • Prepared the application for repository-based data access and easier testing.
  • Improved validation, error handling, and user-specific data access.

Course Outcome Connection

This enhancement primarily demonstrates the use of well-founded computing techniques and tools to implement a solution that provides value. It also demonstrates design decision-making by balancing the additional structure of MVVM against improved maintainability, testing, and scalability.
